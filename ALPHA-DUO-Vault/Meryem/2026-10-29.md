# Günlük — 2026-10-29 (Meryem)

## Yaptıklarım — Material 3 arayüz geliştirme

`https://github.com/hamen/material-3-skill` rehberini kullanarak web ve mobil
arayüzlerini Material Design 3'e uygun hale getirdim.

### Web
Mevcut arayüz (API testleri için) **dokunulmadan** bırakıldı; yeni Material 3
arayüzü ayrı dosyalarda (`web/src/m3/`) eklendi. İki arayüz de çalışır durumda:
- Eski (API test): `index.html` → `src/main.tsx` → `src/App.tsx` + `index.css`
- Yeni (Material 3): `m3.html` → `src/m3/main.tsx` → `src/m3/App.tsx` + `m3/theme.css`

Yeni dosyalar:
- `web/src/m3/theme.css` — MD3 design token'ları (`--md-sys-color-*`, shape, spacing),
  açık + koyu tema (`prefers-color-scheme`), base/component stilleri (tablo, buton,
  form, kart, nav, tab). Sayfaların mevcut `inline-form`/`error`/`warning`/`message`
  sınıfları da token'larla stillendi.
- `web/src/m3/App.tsx` — MD3 app shell (top app bar + nav rail/drawer + içerik);
  mevcut `pages/` bileşenlerini aynen yeniden kullanır (kod tekrarı yok).
- `web/src/m3/main.tsx` + `web/m3.html` — ikinci giriş noktası.
- `web/vite.config.ts` — çoklu sayfa (`index.html` + `m3.html`) build girdisi.

### Mobil (Kotlin / Compose)
PDF gereksinimlerine sadık kalındı (fonksiyon değişmedi; sadece görsel tema):
- `ui/theme/Color.kt` — MD3 baseline açık/koyu renk şemaları (seed #6750A4;
  tüm paired roller: primary/onPrimary, surface/onSurface, container'lar, outline...).
- `ui/theme/Theme.kt` — `AvatarAppTheme`: API 31+ dinamik renk, altına statik
  açık/koyu fallback; `Shapes` (MD3 köşe yarıçapları) + varsayılan `Typography`.
- `MainActivity.kt` — `AvatarAppTheme` sarmalayıcı + `TopAppBar` ("AVATAR Sales").
